NGT Sign Language Recognition

Real-time recognition of Dutch Sign Language (NGT) fingerspelling from a webcam, built as a learning tool with practice and learn modes. MediaPipe hand and face landmarks feed a Random Forest classifier tuned with Optuna, and Dynamic Time Warping handles the letters that need motion (H, J, Z).

  • MediaPipe
  • scikit-learn
  • Optuna
  • OpenCV
